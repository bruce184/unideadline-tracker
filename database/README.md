# Database

This folder stores database-related files for UniDeadline Tracker.

Planned files:

- `schema.sql`: SQL script for creating core tables.
- `seed.sql`: Demo data for local testing and final demo.
- `erd.png`: Entity Relationship Diagram if available.
- `notes.md`: Extra database notes if needed.

Core database:

- Supabase PostgreSQL
- Supabase Auth

MVP tables:

- `profiles`
- `courses`
- `deadlines`
- `reminders`
- `deadline_links`

Important rule:

Do not add group collaboration tables into MVP unless approved.
