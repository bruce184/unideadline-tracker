# Feature Scope

## Allowed MVP

```text
Auth / User Account
Course Management
Deadline Management
Submission Status Tracking
Weekly Dashboard
Reminder & Priority
Search & Filter
Responsive Web App
Basic In-app Reminder
Submission Link Storage
```

## Could-Have After Core MVP Is Stable

```text
Email Reminder
Import PoC
Rule-based Priority Suggestion
Dark Mode
```

Could-have items require team approval before implementation.

## Out of Scope Unless Approved

```text
Group collaboration
Native mobile app
Full LMS/Outlook production integration
Long-term AI risk prediction
Advanced admin analytics
File upload storage API
Multiple links
deadline_links table
deadline_links API
```

## Scope Lock Rule

An assigned task may improve only the assigned feature or layer. If another issue is discovered, record it as out-of-scope and continue with the assigned task.

## MVP Link Decision

Use this field for document/submission URLs:

```text
deadlines.submission_link
```

Do not create separate link storage in the MVP.
